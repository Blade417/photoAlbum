# 星屿 · 3D 星空相册

一个可直接运行的 React + TypeScript + Vite + Three.js 前端工程。照片和视频散布在三维星空中，支持旋转视角、靠近与远离、平移和查看回忆。无需后端服务，素材放入静态目录即可。

## 本地运行

建议使用 Node.js 22 或更新版本。

```sh
npm install
npm run dev
```

在浏览器打开终端显示的本地地址。开发时增删或替换素材会自动重新生成清单，并刷新页面。

```sh
npm run build    # 类型检查并构建到 dist
npm run preview  # 预览构建结果
npm test         # 验证素材扫描、文字配置与保存规则
npm run test:e2e # 浏览器交互验收（默认使用本机 Chrome）
npm run media:scan # 手动重新生成素材清单
npm run media:optimize # 增量生成轻量预览并更新素材清单
```

## 放入自己的照片与视频

将素材放入 **`public/media/`**，统一使用 `memory-` 加编号作为文件名。建议编号补齐三位，从 `001` 到 `099`，最多 99 个回忆。

```text
public/media/
  memory-001.jpg
  memory-002.png
  memory-003.mp4
  memory-003.poster.jpg    # 可选的视频封面
  memory-004.webp
  memory-006.webm          # 允许缺号
  memory-099.jpg
```

- 图片：`jpg`、`jpeg`、`png`、`webp`、`avif`、`gif`。
- 视频：`mp4`、`webm`、`ogg`。实际播放取决于浏览器能否解码文件中的编码；优先使用 H.264 MP4 或 VP8/VP9 WebM。
- `memory-1.jpg` 这种未补零的名称也可以识别，扩展名大小写不敏感。
- 每个编号只对应一个回忆；缺号不会产生空卡片，也不会用演示素材补齐。
- 编号 `0` 和 `100` 及以上不会进入相册，子目录中的素材也不会扫描。
- 同一编号存在多个素材时，优先取三位补零名称，再依次按 `mp4`、`webm`、`ogg`、`jpg`、`jpeg`、`png`、`webp`、`avif`、`gif` 选择，终端会提示重复。建议主动删除不需要的同编号文件，避免歧义。
- 视频封面使用同编号的 `memory-003.poster.jpg`，也支持 `jpeg/png/webp/avif`。封面不单独占用编号；未提供封面仍可打开并播放视频。

启动开发服务器或执行构建时，工程会自动扫描素材并写入 `public/media-manifest.json`，不必手写 99 条数据。清单里的资源路径会经过 Vite 的 `BASE_URL` 处理，适合部署在站点根目录或子目录。

当目录没有有效素材时，项目显示内置的 99 条演示回忆（88 个图片条目、11 个视频条目，复用 12 张照片和 1 段视频）。放入第一份有效素材后，演示相册会整体切换为你的素材。演示资源已经存放在本地，正常运行不需要下载；来源见 [public/demo/SOURCES.md](public/demo/SOURCES.md)。

## 大素材与预览

启动开发服务、构建或执行 `npm run media:optimize` 时，会在本机生成 `public/media-previews/`，原文件保持不变。首次处理大批素材需要一些时间；之后复用缓存，只重新处理新增、替换或缺少预览的文件。

| 用途 | 默认资源 |
| --- | --- |
| 列表、底部缩略图 | 最长边 384 像素的 WebP |
| 星空中的照片 | 最长边 768 像素的 WebP，优先加载视野内照片 |
| 打开的照片 | 最长边 2048 像素的 WebP；下载按钮仍指向原图 |
| 星空中的视频 | 最长边 640 像素、24 帧/秒、最多前 12 秒的静音循环 MP4 |
| 打开的视频 | 按需加载完整原视频，保留声音及播放器控制 |

预览自动校正照片方向，不放大较小的素材，也不保留原图的 EXIF/GPS 元数据。动画图片的星空预览使用首帧，详情保留原动画。视频封面会自动生成，手动提供的同编号封面优先使用。

图片处理最多两张并行，视频逐个转码。星空视频仅加载可见且靠近的素材，电脑最多同时播放 4 个视频源，手机最多 2 个；离开视野约 3.5 秒后释放资源，切换时最多短暂保留 2 个暂停的缓存。手机的照片纹理进一步限制到 512 像素。预览生成失败会在终端提示并回退到原素材，下次启动或扫描会重试。

图片由 Sharp 处理，视频由随依赖安装的 FFmpeg 处理，不上传素材。若需要使用本机已有 FFmpeg，可通过 `FFMPEG_PATH` 指定可执行文件。浏览器展示保持纯静态，无须运行转码服务。

`public/media/` 中的私人素材、`public/media-previews/`、自动生成的清单、个人文案 `public/album-content.json` 均被 Git 忽略；首次启动会在配置缺失时生成默认文案，已有配置不会被覆盖。请单独备份原素材和个人文案。构建后的 `dist/` 仍包含原素材，供原图下载和完整视频播放使用；预览优化减少浏览时的加载量，不会删除发布目录里的原文件。

## 修改文字并保存

点击页面右上角的**编辑文字**按钮，打开文字编辑器：

1. 在“页面文字”中修改相册名称、首页标题、介绍、按钮文字和页脚寄语。
2. 在“照片与视频”中按编号或标题搜索，选中素材后修改它的标题、说明。编号与文件名对应，例如 `memory-003.mp4` 对应 `memory-003`。
3. 点击底部保存按钮，修改即应用到相册；编辑器内也支持 `Ctrl + S` / `⌘ + S`。关闭时如果有未保存的修改，会先提示。

编辑器顶部会明确显示保存位置：

- **保存到项目文件**：通过本机 `localhost` 或 `127.0.0.1` 地址访问 `npm run dev` 时，点击“保存到项目”会直接写入 `public/album-content.json`。刷新、关闭浏览器或重启开发服务后仍保留。文案保存不会自动刷新整页、打断编辑；如果用外部编辑器修改 JSON，请刷新页面读取。
- **保存到本机浏览器**：已发布的纯静态网站、`npm run preview`，以及局域网设备访问开发服务时，点击“保存到本机”只会存入当前浏览器中该站点的草稿。同一域名下不同部署目录的草稿相互隔离；其他设备或访客看不到，清除站点数据后草稿也会消失。页面不会把这类保存说成写入服务器。

把修改发布给所有访客：在本机开发服务保存到项目后，重新执行 `npm run build` 并上传整个 `dist/`。如果是在静态网站中编辑，先点“导出”下载 `album-content.json`，将它替换进源工程的 `public/` 后再构建发布；也可以回到开发服务用“导入”载入 JSON，检查后再点“保存到项目”。导入只载入编辑区，不会未经保存就覆盖原有文案；导出包含当前编辑区内尚未保存的有效修改。

页面文案统一保存在 JSON 的 `site` 中；素材文案按编号保存在 `memories.personal` 中。`memories.demo` 专门保存演示相册文字，不会在加入真实照片时串到个人素材上。没有自定义的编号会使用素材清单中的默认标题和说明；替换同编号素材时，会沿用该编号的自定义文字。相册名称不能为空，其余文案允许清空。

配置示例（下方仅展示素材文案部分，完整文件还需保留 `version` 和 `site`）：

```json
"memories": {
  "demo": {},
  "personal": {
    "memory-001": { "title": "第一次一起看海", "subtitle": "2026 年夏天 · 北海" },
    "memory-003": { "title": "生日快乐", "subtitle": "把这段笑声留在星空里" }
  }
}
```

不需要修改 `media-manifest.json`：它会在扫描素材时重新生成，而独立的 `album-content.json` 会保留你的文字。配置会校验结构、编号 `001–099` 和长度；标题最多 80 字、说明最多 240 字，页面文案长度在编辑框旁显示。项目保存失败或浏览器存储不可用时会明确报错，并保留当前编辑，方便导出备份。

## 浏览方式

- 点击“开始漫游”：从当前分类中随机选择一张照片或视频，用约 3 秒的弧线镜头靠近它，星光随行程温和变亮，抵达后显示对应回忆的标题与入口。重置后再次漫游会重新随机选择，有多份素材时避免连续抵达同一份。可以打开它，也可以继续自由探索。
- 入场期间可以点击“跳过”，也可以直接拖动、滚动或按移动键接管；打开总览或编辑器会停止入场。重置视角后可以再次体验。系统开启“减少动态效果”时直接抵达，不播放镜头飞行动画。
- 靠近回忆后重新开启“自动漫游”：镜头会先平滑拉回较宽的星空视野，再围绕星空中心持续旋转。可随时暂停，也可以拖动或滚动接管；空格键与按钮使用相同的切换方式。
- 鼠标左键拖动：旋转观察角度。
- 鼠标滚轮：靠近或远离。
- 鼠标右键拖动：平移观察位置。
- `W / A / S / D`：向前、向左、向后、向右自由移动；`Q / E`：向下、向上移动。
- `R`：重置视角；`Space`：切换自动漫游；`Esc`：关闭弹窗或退出沉浸模式。
- 星空有远近星点、闪烁星光和发光星芒点缀，随视角产生空间层次。
- 三维画面内可见的视频会自动静音循环播放轻量预览，无需点开；离开画面、切换到总览、打开浮层或后台页面时会暂停并释放闲置资源。电脑最多同时解码 4 个不同的视频源，手机最多 2 个，视野内更近的视频优先；重复使用同一视频的卡片共享播放资源。
- 点击一张照片或视频卡片：打开回忆详情，可用播放器控制播放进度和声音。详情中使用左右方向键或两侧箭头切换回忆。
- 详情中的“在星空中靠近”：回到三维星空并移向当前回忆；下载按钮可保存原始图片或视频。
- “相册总览”：以网格浏览全部回忆，也可以按照片或视频分类。
- 触摸屏：单指旋转，双指缩放和平移。

快捷键在星空视图下使用；操作弹窗、视频控件或按钮时，优先遵循控件自身的键盘行为。原始大图可以直接保留在素材目录，预览会自动生成；完整视频仅在打开详情时加载。

自动播放依赖浏览器策略和视频编码：静音自动播放被浏览器拦截时，首次拖动或点击星空会重试；无法解码的视频保留封面或占位图。详情播放器与星空的静音播放独立。

## 部署

执行 `npm run build` 后，将整个 `dist/` 目录上传到静态网站服务器。`vite.config.ts` 默认 `base: './'`，生成的页面、资源清单和素材均使用相对路径。使用 HTTP/HTTPS 访问；不要通过双击 `dist/index.html` 以 `file://` 打开。

更换部署后的素材时，在源工程里更新 `public/media/` 并重新构建、上传 `dist/`。如果直接在服务器更新文件，需要同步重新生成并上传 `media-manifest.json`；服务器不会自行扫描目录。

`loadMedia()` 返回 `{ items, isDemo, capacity }`。每个素材包含 `id`、`index`、`type`、`src`、可选 `thumbnail`、`title` 和 `subtitle`。素材清单读取失败时会回退到本地演示，同时提供 `warning` 文本供页面展示。清单读取成功但某个文件损坏时，仍需替换该素材文件。
